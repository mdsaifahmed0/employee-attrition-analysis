# Employee Attrition Analysis

## Project Overview

Employee Attrition Analysis is an end-to-end Data Analytics project focused on analyzing employee data to understand attrition patterns, employee status, department trends, tenure, performance, gender, and training outcomes.

## Business Objective

The objective of this project is to analyze employee attrition and identify workforce patterns that can help organizations understand employee retention and make data-driven HR decisions.

## Key Insights

- Total employees analyzed: 2,845
- Overall attrition rate: 13.6%
- Average employee tenure: 2.91 years
- Analyzed employee status, department, performance, tenure, gender, and training metrics.
